# Frameleaf Manager for Synology

Download approved SPK packages and checksums from [Releases](https://github.com/Frameleaf/frameleaf-synology-releases/releases).

Install with **Synology Package Center → Manual Install**. Follow the [installation guide](https://frameleaf.app/docs/nas/synology/) for requirements, checksum verification, DSM setup, upgrades and recovery.

This repository distributes release assets. It does not contain the native application source or provide a Package Center catalog. Manager and the photo-server application are separate releases.
